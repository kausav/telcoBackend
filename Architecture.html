Industry Source Registry — MongoDB Only

Source of truth: MongoDB industry_source_documents plus explicitly persisted scenario_variables.

Runtime boundary

The application does not load industry/domain standards from filesystem resources, static telecom registries, bundled standards files, downloaded standards caches, external URLs, or industry/country profiles.

Proposal

industryType + domain
      ↓
MongoDB industry_source_documents (active JSONs)
      +
MongoDB scenario_variables (optional persisted variables)
      ↓
LLM selection/review only
      ↓
deterministic schema compilation
      ↓
HITL confirmation

Generation gate

active JSON source exists OR persisted scenario variables exist
      ↓ yes
    generate
      ↓ no
HTTP 400 source-of-truth error

Upload

POST /industry-sources/upload accepts exactly industryType, domain, and one multipart file field repeated for one or more JSON files.
